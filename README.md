# 🌐 Sito React

Un sito personale sviluppato con **React**, **Vite** e **Tailwind CSS**, come progetto di apprendimento e base per futuri sviluppi front-end.

## 🚀 Stack Tecnologico

- **React 18**
- **Vite**
- **Tailwind CSS**
- **HeroUI Components**
- **Typescript**
- **Aruba Hosting (static deployment)**
